# IEEE Access class files (provisional)

`ieeeaccess.cls` and the three images come from the third-party repository
https://github.com/erwinrmendez/ieee-access-template (commit e0b3bba, July 2019),
which redistributes the journal's class with the image paths changed to `images/`.
The official template (IEEE Author Center template selector) could not be
downloaded from the build environment. Before submission, replace these files with
the current official IEEE Access template; `main_access.tex` and the paper sources
do not need to change.
