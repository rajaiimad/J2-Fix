# Response to the second-round review (`review_manuscript6.txt`)

Every issue has been fixed at its source. Where a fix involves numbers, they are computed by the analysis code (`scripts/11_posthoc.py`) from the saved predictions and search logs, and the consistency check verifies them automatically. Where a fix concerns wording, the corrected phrasing is added to the check's list of forbidden phrases so that it cannot return.

The consistency check passes **714 / 714** (previously 680). No model was retrained, and no earlier result changed.

## Not changed, and why

- The primary inference is still the group bootstrap, because it was fixed before testing. The sign-flip test is reported as a post-hoc sensitivity analysis.
- E-DDQN was not re-tuned with a different random draw: that would be a new post-hoc model selection. The dependence on the draw is reported instead.
